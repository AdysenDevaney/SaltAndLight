# SaltAndLight

SaltAndLight is being established with an agentic engineering workflow.

## Project workflow

- GitHub Issues are the source of truth for work, specifications, and decision maps.
- Repository-specific agent instructions are in [`AGENTS.md`](AGENTS.md).
- Issue-tracker, triage-label, and domain-document conventions are in [`docs/agents/`](docs/agents/).
- The source workflow guide is included as `Agentic-Engineering-in-GitHub-Copilot-Enhanced 1 (1).pdf`.

Before the first product feature, run `/grill-with-docs` to establish the project glossary and any initial architectural decisions.
