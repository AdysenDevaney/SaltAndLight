# Triage labels

The engineering skills use five canonical triage roles. This file maps those roles to the labels in this repository.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue. |
| `needs-info` | `needs-info` | Waiting on the reporter for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and suitable for an AFK agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment. |
| `wontfix` | `wontfix` | Will not be actioned. |

When a skill mentions a role, use the associated GitHub label. Edit the right-hand column if the team's vocabulary changes.
